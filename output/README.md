# UniDetect Output Directory

This directory stores reports, logs, and alert artifacts generated by UniDetect's passive analysis engine.

## Structure & Purpose
- `alerts/`: Contains structured alert files (e.g. JSON/CSV) generated when suspicious traffic patterns are passively identified.
- `reports/`: Contains summary reports and traffic statistics generated from analyzed PCAP/log inputs.

## Security Notice
Outputs generated in this directory are purely diagnostic and informational. UniDetect does **not** trigger active firewall blocks, dynamic host isolation, or packet responses on the network.
